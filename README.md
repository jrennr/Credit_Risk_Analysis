# Credit risk resampling exercise

An archived notebook exploring class imbalance and resampling approaches for loan status classification, including random oversampling, SMOTE, cluster centroids, and SMOTEENN with logistic regression.

[Inspect the notebook](credit_risk_resampling%20%281%29%20%282%29.ipynb)

**Reproducibility status:** The source CSV is absent and the notebook references a local Windows path. Several cells have undefined variables and no recorded evaluation output. The earlier README's claims of six validated models and specific accuracy, precision, and recall values were unsupported by this repository and have been removed. Do not use this work to make lending decisions.
